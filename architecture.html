2. Step-by-Step Sequential Dataflow

EXECUTION TIMELINE

Trace of a single user voice query traversing each pipeline node within the ~142ms P50 latency budget. 

sequenceDiagram
    autonumber
    actor User as 👤 User
    participant UI as 🖥️ Web UI (app.js)
    participant API as ⚡ FastAPI (/api/query)
    participant STT as 🎙️ Sarvam STT
    participant Embed as 🔢 Dense Embedder
    participant Qdrant as 🗄️ Qdrant HNSW
    participant LLM as 🧠 Groq / Local LLM

    User->>UI: 1. Clicks "Record Voice" & speaks query
    UI->>UI: 2. Renders live waveform visualizer
    User->>UI: 3. Clicks "Stop Recording"
    UI->>API: 4. POST /api/query/audio (WAV)
    API->>STT: 5. Transcribe raw audio
    STT-->>API: 6. Text: "what did chandrayaan-3 discover?" (48ms)
    API->>Embed: 7. Compute dense vector (MiniLM-L12)
    Embed-->>API: 8. 384-dim embedding vector (8.5ms)
    API->>Qdrant: 9. HNSW Cosine Search (ef_search=32, Top-K=5)
    Qdrant-->>API: 10. Top 5 retrieved passage chunks (2.2ms)
    API->>API: 11. Evaluate grounding score & format context (0.8ms)
    API->>LLM: 12. Synthesize factual response with citations
    LLM-->>API: 13. Grounded answer string (68ms)
    API-->>UI: 14. Return JSON payload
    UI->>User: 15. Render answer, evidence cards, and telemetry
